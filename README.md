# AI Automation Builder

A web tool that converts natural language descriptions into complete automation workflows for Zapier, Make.com or custom API setups.

## Features
- NLP analysis of automation requests
- Service detection (Stripe, Notion, Slack, Gmail, etc.)
- Trigger identification with sample payloads
- Step-by-step workflow generation
- Field mapping suggestions
- Zapier-style JSON output
- Built with Next.js, TypeScript, Tailwind, OpenAI Responses API

## Tech
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- OpenAI Responses API (JSON schema)
